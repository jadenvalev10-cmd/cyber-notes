# TryHackMe: OSI Model

Pre Security path, Network Fundamentals module. September 2026.

**Situation:** Room covering the seven-layer OSI (Open Systems Interconnection) model across nine tasks and a practical.

**Task:** Learn each layer's role, key terms, and protocols, then apply the order of the layers in a practical game.

**Action:**

- Task 1, overview: seven layers and encapsulation.
- Task 2, Layer 1 (Physical): hardware, binary signals, Ethernet cables.
- Task 3, Layer 2 (Data Link): MAC addressing and NICs.
- Task 4, Layer 3 (Network): routing with IP addresses; protocols such as OSPF and RIP.
- Task 5, Layer 4 (Transport): TCP (reliable, error-checked) vs UDP (fast, no delivery guarantee) and where each is used.
- Task 6, Layer 5 (Session): setting up and maintaining sessions (handshakes, checkpoints).
- Task 7, Layer 6 (Presentation): translation and standardisation of data, and encryption (for example HTTPS).
- Task 8, Layer 7 (Application): user-facing applications and services such as DNS.
- Task 9, practical: a dungeon-escape game that requires putting the layers in the correct order.

**Result:** Completed the room and can name the seven layers in order and what each does.

**Key terms**

OSI model, encapsulation, Physical, Data Link, Network, Transport, Session, Presentation, Application, MAC address, NIC, IP address, routing, OSPF, RIP, TCP, UDP, handshake, encryption, HTTPS, DNS
