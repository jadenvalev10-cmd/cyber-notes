# TryHackMe: Database SQL Basics

Pre Security path, Software Basics module. September 2026.

**Situation:** Learn how computers store information in databases and how SQL is used to query it, using a café-orders example on a lab VM.

**Task:** Understand how tables are organised, then write basic SQL queries to show, filter, and sort data.

**Action:**

- Task 2, tables: a table organises café orders into rows (individual orders) and columns (the fields describing each order).
- Task 3, SQL queries:
  - `SELECT` chooses what data to display.
  - `FROM` chooses which table the data comes from.
  - `WHERE` filters records by a condition.
  - `ORDER BY` sorts the results.
- Closing reflection: what could happen if someone could change or remove orders without permission. This ties databases to access control.

**Result:** Completed the room and can read and write basic SELECT queries.

**Key terms**

database, table, row, column, SQL, query, SELECT, FROM, WHERE, ORDER BY, filter, sort
