## Key terms

- **Operating system (OS):** the core software that manages hardware, applications, and all system resources.
- **Kernel space:** the OS's highly privileged area with direct hardware access; home of the kernel.
- **User space:** the area where regular applications run with limited permissions, for safety and system stability.
- **Graphical user interface (GUI):** the visual part of the OS (windows, icons, menus) for interacting by clicking or tapping.
- **Command-line interface (CLI):** a text-based interface for controlling the system via typed commands.
