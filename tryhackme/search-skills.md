# TryHackMe: Search Skills

Cyber Security 101 path. October 2026.

Situation: Easy room (about 15 minutes) on where to look for information in offensive and defensive security work. Nobody knows everything, so finding the right answer quickly is a core skill.

Task: Learn the main places to search and use a simulated version of each to find specific information.

Action:

- **Shodan:** a search engine for internet-connected devices, including IoT. It can filter by country, port, organization or ASN, and hostname.
- **VirusTotal:** scans files, URLs, domains, and hashes with 70+ antivirus engines and scanners. Blue teams use it to check what several tools agree on.
- **CVE and CVSS:** CVE IDs look like CVE-YEAR-NUMBER and identify a specific vulnerability. The CVSS score rates how serious it is, based on impact, complexity, and availability.
- **Man pages and vendor documentation:** `man <command>` explains a tool, like `nc` (netcat), and official docs are the most reliable source.
- **GitHub:** a good place for proof-of-concept (PoC) code and write-ups. Verify before running anything, since some PoCs are flawed or even malicious.

Result: Completed the room. I can choose the right resource for the question, whether it's finding exposed devices, checking a suspicious file, or looking up a vulnerability.

Key terms

IoT, Shodan, ASN, VirusTotal, CVE, CVSS, man page, netcat (nc), proof of concept (PoC)
