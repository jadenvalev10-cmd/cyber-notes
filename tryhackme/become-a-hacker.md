# TryHackMe: Become a Hacker

Pre Security path, Attacks and Defenses module. October 2026.

**Situation:** Easy room (about 30 minutes) that closes the Attacks and Defenses module and the Pre Security path. Introduces offensive security, the role of an ethical hacker, and the hacker mindset, then applies them to a web application.

**Task:** Learn the offensive security terminology and methodology, then use real red-team techniques against a web app.

**Action:**

- Worked through all four tasks, including finding and exploiting weaknesses.
- Used enumeration to gather details on the target, found credentials, and ran a dictionary attack against the login.
- Roles covered: penetration tester / ethical hacker, vulnerability researcher, red team operator.

**Result:** Worked through the whole room. Suggested next paths: Become a Defender, Cyber Security 101, Jr Penetration Tester, SOC Level 1.

**Key terms**

scope (systems and actions allowed in a test), vulnerability (a weakness), exploit (technique using a vulnerability), enumeration (collecting details on a system, users, and services), credentials, authentication, dictionary attack (guessing from a wordlist)
