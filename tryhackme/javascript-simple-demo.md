# TryHackMe: JavaScript: Simple Demo

Pre Security path, Software Basics module. September 2026.

**Situation:** Read and run a basic JavaScript game in a browser-based VS Code lab machine. This room follows Python: Simple Demo, so the same ideas appear in a second language.

**Task:** Understand variables, conditional statements, and loops (while), then run the game.

**Action:**

- Task 2, variables: a variable is a named container for a value.
- Task 3, prompting the user for input: the program asks the player for a value and stores it in a variable.
- Task 4, conditional statements: if / else runs different code depending on whether a condition is true or false.
- Task 5, iterations: a while loop repeats its code for as long as its condition holds.
- Ran the game and compared the structure to the Python version.

**Result:** Can explain the program flow of the game and how the same concepts map between Python and JavaScript.

**Key terms**

variable, conditional, if / else, loop, while loop, iteration, imperative programming (ordered instructions)
